# 文献线

写内容前先找文献依据。这一份只管“从资料到带出处的内容”。

## 引用闸门

这是整个文献线的核心。每一条引用必须来自这次任务里的一次真实检索。

五步：

1. **拆论点。** 把要写的内容拆成若干条论断，一条一句。
2. **生成检索词。** 每条论断给 2-3 个检索词，用专业词，不用口语。中英文各试一次。
3. **调接口拿记录。** 优先运行 `python <skill_dir>/scripts/lookup.py "<关键词>" --abstract --json`（如关注近几年进展可加 `--year-from <YYYY>`），或按 `references/sources.md` 里的地址检索，拿回真实的标题、作者、年份、DOI 或 arXiv 编号。
4. **只引用检索结果里的条目。** 模型记忆中的文献一律不算——**包括 *Attention Is All You Need* 这类人尽皆知的经典论文**，也必须走本次接口检索取回真实元数据再引用。
5. **参考文献表从接口元数据生成。** 不手打，格式见 `references/citation-formats.md`。

四条禁令：

- 检索不到，就写“这段没有找到公开文献支持”，然后把这条论断降级成推测，或者直接删。
- 不写“研究表明”“有学者指出”“大量文献证实”这类没有具体编号的说法。要么给出处，要么不写。
- 不为凑数把只沾一点边的文献塞进参考文献表。三条扎实的比十条勉强的强。
- 作者、年份、期刊名、卷期页码全部来自接口返回，改一个字都不行。

## 三档流程

按输入现状进入对应档位：手上有材料先走**第一档**，仅当用户明确要求补充外部文献时再衔接**第二档**（不可丢开材料自由发挥）；无材料直接走**第二档**；确证有源正常返回却无结果时才进入**第三档**（接口全失败禁止误入第三档）。

### 第一档：有材料

用户上传了 PDF、课件、论文、图片。

1. 读材料，把章节骨架提出来（一级标题、二级标题）。
2. 按这个骨架组织内容，不要另起一套结构。
3. 每条观点的出处指到章节或页码，格式：`（《文件名》第 3 章）`。
4. 材料本身带参考文献的，在联网条件下抽出来用接口核一遍是否真实存在（优先用 `python <skill_dir>/scripts/lookup.py --doi <DOI> --json` 精准反查；无 DOI 时用关键词检索，比对**标题、第一作者、年份**三者一致才算“找到”）。核不到的单独列出提醒用户。

**离线规则**：这一档不联网也能做。离线或接口不可达时跳过第 4 步在线核验，在核验表对应行注明“未核验（离线未连网）”，**严禁**写成“未找到”。材料里有什么写什么，材料里没有的不补。

### 第二档：只有主题

用户给了一个题目或方向。

1. 拆论点。
2. 检索：`lookup.py` 默认并发查询 Crossref（书目）、OpenAlex（开放获取链接）、arXiv（理工科预印本）、DBLP（计算机/AI 顶会期刊），有需要开放期刊补充时可加 `--sources ...,doaj`；中文方向的检索方式见 `references/sources.md` 的中文一节。
3. **只基于摘要和拿得到的全文写。** 摘要没说的细节不能写。**若某条记录仅有题录、无摘要且拿不到全文，只可列出题录，严禁凭标题脑补其方法或实验结论。**
4. 输出综述框架：论点、论据、每条论据挂一条引用。
5. 附覆盖说明：查了哪些源、命中多少条、哪些子方向是空白。

### 第三档：检索不到

**前置条件：只有在至少一个检索源正常返回（脚本退出码为 0 或 1）时才能进入第三档。** 若所有源均因断网或 429/403 限流失败（退出码 3），严禁写“公开文献很少”或“研究空白”，必须如实报告检索未完成。

某个方向几乎搜不到东西。这本身是有用的结论。

1. 直接说“这个方向公开文献很少”。
2. 给三条替代路径：换检索词、换语言（中英互换）、放大或缩小范围。
3. 不要拿相近领域的文献充数，也不要提高抽象层次硬凑一段。

## 文献线硬规则

除 `SKILL.md` 共用的四条外，补充文献线专属规则：

1. **摘要是摘要。** 摘要说了什么就写什么，摘要没说的实现细节、实验数字，一个字都不能编。
2. **中文文献的缺口要如实说。** 知网、万方、维普需要机构账号，进不去。搜不到中文文献时明确讲“中文文献本轮未覆盖”，不要拿英文文献假装覆盖了国内研究。
3. **文献的观点和用户的观点分开。** 你的任务是归纳和整理，不是替用户立论。用户自己的判断单独标出来。
4. **数量服务于论证。** 一段话有两条扎实引用就够，不要为了看起来充分堆到八条。
5. **每条引用都要能点开。** 有 DOI 就给 DOI 链接，有 arXiv 编号就给 abs 链接。

## 需要打断用户的三种情况

- 主题太宽（“人工智能”这种），先问清是哪门课、哪个子方向
- 上传的材料读不出文字（扫描件、加密 PDF），或用户上传了知网 `.caj` 专有格式文件（无法直接读取），先说明并提醒用户**在知网下载页面改选“PDF 下载”或用 CAJViewer 转为 PDF 后再上传**
- 需要用户自己下载的中文文献，先讲清为什么要他下

一次问完，不要来回追问。
